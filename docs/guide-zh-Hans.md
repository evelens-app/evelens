# GridSight 用户指南

> 本指南介绍的是 **GridSight 1.0.0-beta.2**。标有 *(beta.2+)* 的功能在 1.0.0-beta.1 中没有。

本指南介绍如何安装、设置和使用 GridSight——一款面向 Windows 上 EVE Online 多开玩家的免费辅助工具。下文中的按钮和菜单名称均与 GridSight 简体中文界面中的显示完全一致。

GridSight 不会向游戏发送任何输入，不读取客户端内存，也不修改游戏文件。它读取 EVE 写入磁盘的日志，使用官方 ESI API 和少数几个 EVE 社区公开服务，并在你的屏幕上显示信息。它唯一可能修改你 EVE 账号的内容是已保存的装配——而且只有在你明确运行命令行导出时才会发生（第 14 节）。

## 1. 系统要求

- **Windows 10 或 11，64 位（x64）。** 无需安装 .NET 或其他组件——GridSight 只是一个 `GridSight.exe` 文件，运行时已打包在内。
- **EVE 使用「窗口」或「无边框窗口」模式。** 在独占**全屏**模式下游戏会独占屏幕：GridSight 的窗口（缩略图、伤害浮窗、延迟/FPS 浮窗）无法显示在游戏上方。请使用「窗口」或「无边框窗口」。
- **内存：** 同时运行 5 个客户端时约占用 115–150 MB 内存（「面板」窗口关闭时）；CPU 占用通常远低于 1%。
- **「面板」窗口** *(beta.2+)* 使用 Microsoft Edge 的 **WebView2 Runtime** 组件。Windows 11 自带；Windows 10 上有时需要另行安装——此时「面板」会显示「下载 WebView2 Runtime」，在安装之前可以先用「在浏览器中打开」。
- **网络** 仅用于可选功能：ESI 登录和「面板」、情报地图和舰船分类（一次性下载 CCP 静态数据，约 95 MB）、市场价格和估价、zKillboard 和检查更新。缩略图和警报离线也能使用。

## 2. 分步安装

> [!WARNING]
> **GridSight 没有进行代码签名。**
> 代码签名证书每年约需 200–400 美元，对一个独立的免费项目来说暂时负担不起。因此 Windows 无法告诉你这个文件是谁制作的，首次运行时 SmartScreen 会弹出蓝色窗口：
>
> **「Windows 已保护你的电脑」**
>
> Windows 会对没有数字签名、也没有下载记录的新文件显示这个窗口。这并不表示发现了恶意软件。如果文件是从官方 Releases 页面下载的，并且 SHA-256 一致（第 1 步），请点击 **更多信息**，然后点击 **仍要运行**。
>
> 如果 `GridSight.exe` 来自其他任何地方——请不要运行。如果你的电脑由单位统一管理，或 Windows / 杀毒软件直接拦截了文件且没有「仍要运行」选项，请不要设法绕过。

### 第 1 步：下载并校验文件

1. 打开 Releases 页面：**https://github.com/evelens-app/evelens/releases**，从最新版本下载 `GridSight.exe`。不要从其他网站、论坛、Discord 或网盘下载 GridSight——即使文件名相同也不行。
2. 浏览器可能提示该文件「不常被下载」。对新程序来说这很正常：打开下载菜单（「…」）并选择 **保留**。
3. **首次运行前核对 SHA-256。** 在文件所在文件夹中打开 **PowerShell** 并运行：
   ```powershell
   Get-FileHash .\GridSight.exe -Algorithm SHA256
   ```
   `Hash` 的值必须与你所下载版本的版本说明中给出的 SHA-256 完全一致（不区分大小写）。如果不一致——请删除文件，并重新从 Releases 页面下载。如果仍不一致，请不要运行，并私下报告（见 [SECURITY.md](../SECURITY.md)）。
4. 哈希一致只能证明该文件与作者发布的文件逐字节相同，本身并不能证明文件是安全的——GridSight 做什么、有哪些局限，见 [SECURITY.md](../SECURITY.md)。包含更多检查方法的分步说明：[DOWNLOAD_VERIFICATION.md](../DOWNLOAD_VERIFICATION.md)（英文）。

### 第 2 步：把 GridSight.exe 放到单独的文件夹

GridSight 无需安装——文件放在哪里就从哪里运行。请为它选一个固定位置，例如：

```
%LOCALAPPDATA%\Programs\GridSight\
```

（把这段粘贴到资源管理器地址栏，新建 `GridSight` 文件夹，并把 `GridSight.exe` 移进去），也可以使用你自己的任意文件夹。

- **不要**留在「下载」文件夹里——那里很容易被误删。
- **不要**放进 EVE 游戏文件夹。
- GridSight 不会在 exe 旁边写入任何文件。设置、布局、日志等数据保存在 `%APPDATA%\GridSight\`，「面板」报告保存在 `%USERPROFILE%\eve-snapshot\`（完整列表：[PRIVACY.md](../PRIVACY.md)）。
- 如果开启了开机自启，GridSight 会记住 exe 的路径。之后若移动了文件，请把「随 Windows 启动 GridSight」关闭后再重新打开。

### 第 3 步：去掉「从网络下载」标记

1. 右键点击 `GridSight.exe` → **属性**。
2. 在 **常规** 选项卡底部勾选 **解除锁定**（如果没有这个复选框，说明文件已经解除锁定）。
3. 点击 **确定**。

### 第 4 步：首次运行与 SmartScreen

双击 `GridSight.exe`。如果出现 **「Windows 已保护你的电脑」** 窗口且哈希一致，点击 **更多信息** → **仍要运行**（见本节开头的警告）。通常每个文件版本 Windows 只会询问一次。

*(beta.2+)* 第一次启动时，GridSight 会显示 **「欢迎 — GridSight」** 窗口：托盘图标在哪里、接下来做什么，以及「当前状态」——找到了几个 EVE 客户端、是否找到了游戏日志文件夹（如果没有，请通过「打开设置」→「常规」指定）。窗口中还有本指南、SECURITY 和 PRIVACY 的链接。点击「知道了」或勾选「不再显示」；GridSight 会继续在托盘中运行。

### 第 5 步：如果杀毒软件报警

有些杀毒软件对新的未签名文件，以及 GridSight 确实用到的功能（单文件 exe 会把运行时解压到 `%TEMP%`、可选的开机自启、用于 FPS 的 Windows 性能跟踪、全局热键）比较敏感。处理方法：

- **不要关闭杀毒软件。**
- 先核对 SHA-256（第 1 步）。哈希不一致的文件确实有问题——请删除。
- 如果哈希一致，可以通过杀毒软件厂商的官方表单把文件作为可能的误报提交，并在 [Issues](https://github.com/evelens-app/evelens/issues) 中告诉我们：使用的是哪款杀毒软件、它报告了什么。
- 如果你确信是误报，可以**只为这一个文件**添加排除项。在 Microsoft Defender 中：**Windows 安全中心** → **病毒和威胁防护** → 在「病毒和威胁防护设置」下点击 **管理设置** → **排除项** → **添加或删除排除项** → **添加排除项** → **文件** → 选择 `GridSight.exe`。
- 如有疑虑，请不要运行。

### 第 6 步：检查 EVE 客户端设置

1. **窗口模式：** 在 EVE 的显示设置中选择 **「窗口」** 或 **「无边框窗口」**（不要用全屏）。
2. **聊天记录：** 本地警报和情报功能读取的是聊天日志，因此 EVE 必须把聊天内容写入文件。请在 EVE 设置（Esc 菜单）中找到「将聊天记录保存到文件」的聊天选项（英文客户端中为 **「Log Chat to File」**）并确认已开启。否则本地和情报功能无法工作（缩略图和战斗警报不受影响）。
3. **游戏日志（Gamelogs）**——战斗、跃迁扰断、货柜舱、采矿——由 EVE 自动写入，无需开启任何选项。
4. **日志文件夹：** EVE 默认把日志写到 `文档\EVE\logs`（子文件夹 `Gamelogs` 和 `Chatlogs`）。如果「文档」文件夹已被移到 OneDrive，路径类似 `…\OneDrive\文档\EVE\logs`。两种情况 GridSight 都会自动找到（见[第 6 节](#6-eve-日志文件夹和客户端语言)）。

### 第 7 步：启动后会看到什么

- GridSight 图标会出现在任务栏右下角、时钟旁边的系统托盘中。Windows 常把新图标藏在 **^** 箭头下面。想让它一直可见，可以把图标从 **^** 区域拖到任务栏上，或打开 **设置 → 个性化 → 任务栏 → 其他系统托盘图标**（Windows 11）并打开 GridSight。
- **双击** 图标打开设置，**右键** 打开菜单。
- EVE 客户端一运行，每个客户端都会出现一个缩略图。客户端停留在角色选择界面时，缩略图上显示「登录中…」。
- 如果托盘菜单中显示「⚠ 未找到 EVE 日志文件夹」，说明这台电脑上还没运行过 EVE，或者日志在别的位置——见[第 6 节](#6-eve-日志文件夹和客户端语言)。

### 第 8 步：不需要的功能可以关闭

设置中的所有更改都会立即生效并自动保存——没有「保存」按钮。

| 功能 | 默认 | 在哪里关闭 |
|---|---|---|
| 延迟与 FPS | 关 | 托盘：「延迟/FPS：缩略图」「延迟/FPS：主窗口」；或 设置 →「常规」→「延迟与 FPS」 |
| 伤害监视器 | 关 | 托盘：「伤害监视器」；设置 →「伤害」 |
| 情报 | 关 | 设置 →「警报」→「监视情报频道」 |
| 单项警报类型 | 开 | 设置 →「警报」（所有角色）或「角色」（单个角色） |
| 临时停用所有警报 | — | 托盘：「暂停警报」 |
| 检查更新 | 开 | 设置 →「常规」→「检查更新（每天一次，GitHub）」 |
| 开机自启 | 关 | 设置 →「常规」→「随 Windows 启动 GridSight」 |
| 账号计时器 | 开（需先在「面板」中连接角色才会工作） | 设置 →「常规」→「监视账号计时器」 |
| 交易历史后台同步 *(beta.2+)* | 开（仅在账号计时器开启时生效） | 设置 →「常规」→「账号计时器」→「积累交易历史（每小时）」（第 13 节） |
| 市场订单监控 *(beta.2+)* | 开（仅在账号计时器开启且已在「面板」中连接角色时生效） | 设置 →「常规」→「账号计时器」→「监控我的市场订单（被超价、即将过期）」（第 13 节） |

### 第 9 步：更新

1. 从 Releases 页面下载新的 `GridSight.exe` 并核对 SHA-256（第 1 步）。
2. 关闭 GridSight：右键托盘图标 → **退出**。
3. 在同一文件夹中用新文件替换旧的 `GridSight.exe`，并解除锁定（第 3 步）。
4. 启动。设置、缩略图位置、已连接的角色和交易历史都会保留——它们保存在 `%APPDATA%\GridSight\`。

### 第 10 步：卸载

1. 如果开启了开机自启，先取消勾选「随 Windows 启动 GridSight」——或之后在注册表编辑器中删除 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下名为 `GridSight` 的值。
2. 可选：断开角色——「角色」选项卡中的「断开 ESI」，以及 *(beta.2+)*「面板」窗口中的「断开」（第 12–13 节）。
3. 托盘图标 → **退出**。
4. 删除 `GridSight.exe`（如果用过，也删除 `GridSight.Snapshot.exe`）。
5. 删除 `%APPDATA%\GridSight` 文件夹：设置、布局、登录令牌（`tokens.bin`、`snapshot-tokens.bin`）、交易历史（`history.db`）、资产总值历史（`networth.json`）、「面板」的 WebView2 配置文件（`webview2\`）、日志和缓存。
6. 删除 `%USERPROFILE%\eve-snapshot`——「面板」报告和 ESI 原始数据（钱包、资产、位置等，**未加密**）。
7. 如果以前用过 EveLens（旧名称），也请删除 `%APPDATA%\EveLens`——其中可能还留有登录令牌的旧副本。
8. 可选：删除 `%TEMP%\GridSight-logs`（备用日志文件夹）。
9. 如果授予过 FPS 权限（第 11 节），请在删除 GridSight *之前* 把自己移出该组：*(beta.2+)* 使用「常规」→「延迟与 FPS」中的「撤销 ETW 权限（UAC）…」，或**以管理员身份打开命令提示符**，运行 `net localgroup "Performance Log Users" %USERNAME% /delete`（非英文 Windows 中组名可能是翻译后的——GridSight 会在「授予 FPS 权限（UAC）…」按钮下方显示准确的命令）。然后注销 Windows 并重新登录。
10. 如果通过 ESI 连接过角色，请在 CCP 网站上撤销访问权限：https://community.eveonline.com/support/third-party-applications/。仅删除本地文件并不会撤销访问权限。

同样的清单及说明见 [PRIVACY.md](../PRIVACY.md) 第 8 节。

## 3. 隐私与安全

**没有 GridSight 服务器，没有遥测，没有统计分析。** GridSight 没有自己的服务器和账号系统，不会向作者发送任何数据。EVE 的游戏日志和聊天日志只在你的电脑上读取，不会上传到任何地方。

**GridSight 在你电脑上读取什么：** EVE 写入的日志文件（只读；只读游戏日志、本地频道和你自己选择的情报频道）；剪贴板——仅在你打开剪贴板解析窗口时；用于延迟/FPS 的 Windows 性能数据（ETW）——仅在你开启该功能时。它从不读取游戏内存，也从不向游戏发送输入。

**网络。** GridSight 会连接 EVE 官方服务（SSO 登录、ESI API、图片服务器、静态数据）、zKillboard、Fuzzwork 市场价格，以及用于检查更新的 GitHub API。在你没有任何操作时，它可能会：每天检查一次 GitHub 更新（如已开启）；为已连接角色约每 30 秒刷新一次 ESI 标签；每 10 分钟检查账号计时器，并约每小时同步一次交易历史 *(beta.2+)*；最多每周下载一次 EVE 静态数据。其他一切只在你使用相应功能时才会发生。完整列表——发送什么、发往哪里、何时发送、如何关闭——见 [NETWORK_CONNECTIONS.md](../NETWORK_CONNECTIONS.md)（英文）。

**电脑上保存了什么：** 设置、加密的登录令牌、你的交易历史和资产总值历史 *(beta.2+)*、公开数据缓存、日志，以及 `%USERPROFILE%\eve-snapshot` 中的「面板」报告。报告、交易历史和资产总值历史**未加密**——除非你愿意公开这些信息，否则不要分享这些文件或「面板」截图。详情及如何全部删除：[PRIVACY.md](../PRIVACY.md)。

**登录令牌** 只保存在这台电脑上，使用 Windows DPAPI 针对你的 Windows 账户加密——其他 Windows 用户无法解密（以你本人账户运行的程序可以）。令牌只会发送到 CCP 自己的服务器：发往 `login.eveonline.com` 以续期访问权限，以及随每个授权请求发往 `esi.evetech.net`——从不发给作者或任何第三方。GridSight 永远看不到你的 EVE 密码：你是在 EVE 官方网站上登录的。请求了哪些权限、为什么需要：[ESI_PERMISSIONS.md](../ESI_PERMISSIONS.md)。

**CCP 的规则。** GridSight 在 EVE 开发者门户上使用自己的应用注册，并按照我们对 [CCP 开发者许可](https://developers.eveonline.com/license-agreement) 和 EULA 的理解来设计。它**未经** CCP 或 Fenris Creations 审核或批准；在开发者门户上注册并不代表认可。EVE Online 的开发商是 Fenris Creations 工作室（2026 年 5 月前名为 CCP Games）；许可由 CCP hf. 授予。GridSight 与 Fenris Creations / CCP 无任何关联。

**局限。** exe 没有代码签名，源代码不公开，目前也还没有经过独立审计。GridSight 对 EVE 和 Windows 做了什么、它的局限，以及如何私下报告安全问题：[SECURITY.md](../SECURITY.md)。

**撤销访问：** 可随时在第三方应用页面撤销：https://community.eveonline.com/support/third-party-applications/

## 4. 托盘图标和设置窗口

**打开设置：** 双击托盘图标，或右键 →「设置…」。

**托盘菜单**（右键），从上到下：

- 「有新版本 X…」——仅在有新版本时出现；打开发布页面。
- 「计时器」——账号计时器（第 13 节），开启计时器时可见。
- 「面板」*(beta.2+)*——「面板」窗口（第 13 节）。
- 「市场速览」*(beta.2+)*——直接打开「面板」的「市场速览」部分（第 13 节）。
- 「解析剪贴板（定向扫描 / 本地 / 估价）」——第 9 节。
- 「采矿」——第 10 节。
- 「伤害监视器」——开关伤害浮窗。
- 「编辑模式」——移动缩略图、调整大小。
- 「设置…」
- 「重新连接 ESI…」——仅当某个角色的 ESI 访问已过期或被撤销时出现。
- 「延迟/FPS：缩略图」「延迟/FPS：主窗口」——第 11 节。
- 「暂停警报」——暂时不显示新警报。
- 「Язык / Language」——界面语言。
- 「帮助与反馈」*(beta.2+)*——子菜单：「使用说明」（打开本指南）、「报告错误」和「建议功能」（在浏览器中打开 GitHub Issue 表单——不会自动发送任何内容）、「安全与隐私」（打开 SECURITY.md）、「检查更新」。在 1.0.0-beta.1 中这里只有「使用说明」。
- 「关于」——版本、链接、检查更新、支持作者。
- 「退出」

**设置选项卡：**

| 选项卡 | 内容 |
|---|---|
| 「角色」 | GridSight 见过的所有角色：是否在线、分组、单个角色的警报、「连接 ESI」按钮。 |
| 「分组与热键」 | 角色分组以及在组内切换的热键。 |
| 「警报」 | 启用哪些警报、「测试」按钮、本地和情报设置。 |
| 「伤害」 | 伤害监视器。 |
| 「常规」 | 语言、EVE 日志文件夹、缩略图、编辑模式热键、剪贴板解析、采矿、「面板」热键、zKillboard 联系方式、延迟与 FPS、启动与更新、账号计时器、通知（免打扰时段）、迁移到另一台电脑、ESI Client ID。 |

窗口底部有「关于 / 支持」链接。

## 5. 缩略图

**布局。** 每个角色的缩略图都有各自的位置和大小，并按角色保存，因此客户端重启后缩略图会回到原位。新缩略图宽 320 像素。缩略图保持客户端窗口的宽高比（形状不同时会留黑边）。

**编辑模式**——默认热键 **`Ctrl+Alt+E`**（或托盘 →「编辑模式」）：

- 拖动缩略图即可移动；缩略图之间会自动吸附；
- 拖动右下角调整大小（最小宽度 120 像素）；
- 松开鼠标后位置和大小立即保存；
- 再次按 `Ctrl+Alt+E` 退出编辑模式。

编辑模式热键可在「常规」→「编辑模式」中修改。

**切换。** 点击缩略图即可把该客户端切换到前台。已最小化的客户端显示「已最小化」，点击后会恢复。

**外观**（「常规」→「缩略图」）：

- 「不透明度」——30–100%，作用于整个缩略图窗口；
- 「隐藏当前活动客户端的缩略图」——这个客户端你本来就看得到；
- 「EVE 不在前台时隐藏所有缩略图」——在浏览器、Discord 等程序中时缩略图会隐藏。

**分组与热键**（「分组与热键」选项卡）：

1. 点击「添加」，在「分组名称」中命名（例如「舰队」）。
2. 在下方列表中选择角色并点击「加入分组」。对每个角色重复此操作。也可以在「角色」选项卡中为角色选择分组。
3. 设置「下一个角色」和「上一个角色」：点击输入框后按下组合键，例如 `Ctrl+Alt+F1`。不带 Ctrl/Alt/Shift/Win 时只能用 F1–F24；仅 Shift 不够；不能使用 Alt+F4。Backspace 清除，Esc 取消。
4. 「切换顺序」为从上到下：拖动行或使用「上移」/「下移」。未运行客户端的角色会被跳过。

如果组合键已被其他程序或 GridSight 的其他热键占用，GridSight 会以红字提示——请换一个。

## 6. EVE 日志文件夹和客户端语言

**自动检测。** GridSight 会在 `文档\EVE\logs` 中查找日志，并以「文档」文件夹的实际位置为准——包括被 Windows 移到 OneDrive 的情况（`…\OneDrive\文档\EVE\logs`）。如果该文件夹还不存在（EVE 从未运行过），GridSight 会等待，一旦出现就自动接入。

**检查：**「常规」→「EVE 日志文件夹」。路径下方显示：

- 「已找到：正在读取 Gamelogs 和 Chatlogs。」——一切正常；
- 「未找到 Gamelogs 文件夹——警报无法工作。…」——请手动指定文件夹。

**手动指定：** 点击「浏览…」，选择 `EVE` 里的 `logs` 文件夹（包含 `Gamelogs` 和 `Chatlogs` 的那个），或把路径粘贴到输入框中。

**用于解析日志的 EVE 客户端语言。** 警报、伤害、采矿和本地都是根据游戏日志的文本识别的，所以 GridSight 需要知道客户端语言。它与 GridSight 界面语言无关。「常规」→「语言」→「EVE 客户端语言（用于解析日志）」：

- 「自动（根据日志文本）」——默认，根据日志文本识别俄文和英文客户端；
- 「RU — 俄文客户端」/「EN — 英文客户端」——只使用该语言的匹配模板。

> [!NOTE]
> 警报、伤害监视器和采矿目前针对 **俄文** EVE 客户端调校并验证。**英文** 客户端支持仍在测试中——如果在英文客户端上有功能不触发，请在 Issues 中反馈。其他客户端语言（中文、德文等）暂不支持日志解析：缩略图、切换、定向扫描/本地分析和 ESI 可以使用，但基于日志的警报不可用。

## 7. 警报

警报**只以缩略图的彩色边框显示——没有声音**。边框先闪烁 5 秒，之后保持高亮，直到你切换到该客户端。活动客户端（位于前台）永远不会触发警报——你本来就在看它。

| 颜色 | 警报 | 何时触发 |
|---|---|---|
| 橙色 | 「跃迁扰断（你被拦住了）」 | 你被跃迁扰断器或跃迁干扰器拦住 |
| 红色 | 「攻击（舰船正在受到伤害）」 | 你的舰船正在受到伤害 |
| 紫色 | 「Intel（情报频道中出现角色附近的星系）」 | 见第 8 节 |
| 黄色 | 「舰船（货柜舱已满）」 | 货柜舱已满（也包括采矿中的舱容估算，第 10 节） |
| 青色 | 「本地（星系频道中的消息）」 | 本地频道有消息、切换星系，或关注名单中的人发了消息 |

如果同时有多个警报，显示最重要的一个（顺序同上表），其余以小彩色圆点显示。

**设置（「警报」选项卡）：**

- 复选框为所有角色开启或关闭某类警报；单个角色的开关在「角色」选项卡中；
- 每类警报旁的 **「测试」** 会让所有已打开的缩略图以该颜色高亮——方便快速查看效果；
- 「本地警报何时触发」：「本地频道中的任何消息」、「切换星系」，以及名单「这些名字发消息时总是报警（每行一个）」。

EVE 不会在日志中记录谁进入了本地频道，因此无法实现「星系中出现中立」警报。角色登录游戏以及你自己角色发的消息不会触发本地警报。

**暂停：** 托盘 →「暂停警报」——取消勾选前，新事件不会点亮边框。

## 8. Intel 情报

GridSight 可以读取你的情报频道，并高亮附近星系被报告的角色。

1. 确认 EVE 中已开启聊天记录（第 2 节第 6 步）。
2. 「警报」→「情报」→ 勾选 **「监视情报频道」**。
3. 在「频道」中填写频道名称，每行一个，与聊天日志文件名开头一致（`Chatlogs` 中形如 `<频道>_YYYYMMDD_HHMMSS_….txt` 的文件）。不区分大小写。
4. 设置「半径：」——1 到 15 跳（默认 5）。

首次启用时，GridSight 会下载 CCP 静态数据（约 95 MB）来构建星门地图；状态显示在滑块下方（「地图已加载：… 个有星门的星系。」）。

**工作原理：** 如果频道消息中提到的星系距某个角色当前所在星系不超过半径（按星门跳数计算），该角色的缩略图会以紫色高亮，状态条显示 `Intel：<星系> · <N> 跳`（最近的一个）。角色所在星系取自本地频道或 ESI；未知时不对该角色计算情报。

**解除：** 包含 **`clr`** 或 **`clear`**（也支持俄文 `чисто`）的消息会解除同一条消息中提到的星系的警报，例如 `Perimeter clr`。切换到该客户端也会解除。

限制：不识别缩写和后缀（如「1DQ」「Urlen-gate」）；名称为普通单词的星系（`Bar`、`Exit`、`Pain`、`Dead End` 等）只有按游戏中的大写写法书写时才会识别。星系名称需使用英文（拉丁字母）。虫洞星系会被忽略。

## 9. 定向扫描、本地分析与估价

GridSight 只在你打开这个窗口时读取剪贴板中的文本——不会向游戏发送任何内容。

**在游戏中如何复制：**

- **定向扫描：** 在扫描窗口中点击结果列表，按 `Ctrl+A`，再按 `Ctrl+C`。
- **本地：** 在聊天窗口中选中成员（点击第一个，Shift+点击最后一个，或 `Ctrl+A`），再按 `Ctrl+C`。
- **要估价的物品** *(beta.2+)*：在物品栏窗口（货柜舱、机库、集装箱）中选中物品，必要时按 `Ctrl+A`，再按 `Ctrl+C`。

**打开解析窗口：** 托盘 →「解析剪贴板（定向扫描 / 本地 / 估价）」，或使用自定义快捷键：「常规」→「剪贴板解析（定向扫描 / 本地 / 估价）」→「打开解析窗口」（默认未设置）。窗口会自动识别格式；「定向扫描」/「本地」/「估价」按钮可对当前文本强制使用某种模式。复制新内容后，点击「重新粘贴」或再次按快捷键。

**定向扫描结果：** 舰船和其他对象的数量；按级别和型号列出的舰船；「注意」区块列出危险舰船（拦截舰/重型拦截巡洋舰、移动跃迁扰断泡、战斗扫描探针、截击舰、侦察舰、隐形轰炸舰、黑隐特勤舰、后勤舰、旗舰、超级旗舰）。「仅限同一网格（≤ 10 000 km）」会隐藏远处的对象。

**本地结果：** 按联盟和军团分组的飞行员，人数多的排在前面（名字通过公开的 ESI API 识别——粘贴的名字会发送给 ESI）。你已连接角色所在的军团和联盟以绿色「己方」标出。「用 zKill 检查」（仅在点击时）会查询最大群组中最多 20 名非己方飞行员的击毁/损失；点击飞行员名字可打开其 zKillboard 页面。

**估价结果** *(beta.2+)*：「买单总额」「卖单总额」「体积（打包）」和项数，下方是按物品列出的表格，包括买单价、卖单价和一条提示——「直接卖给买单」或「挂卖单」。在「交易中心」中选择交易中心（Jita、Amarr、Dodixie、Rens、Hek）。价格为 Fuzzwork 对该交易中心空间站的汇总数据（取最优一侧订单簿的 5%），每小时更新；为了获取价格，GridSight 会把交易中心和物品类型 ID 列表发送给 Fuzzwork。无法对应到物品的行列在「未识别」中。「复制汇总」会把简短汇总（交易中心、总额、体积、项数）复制到剪贴板。第一次估价会加载 CCP 静态数据（SDE），可能需要几分钟。

提示：在「常规」→「zKillboard 联系方式」中可以填写可选的联系方式（邮箱、游戏角色名或 Discord）——zKillboard 希望工具能表明身份。该联系方式会放在请求头中发送给 zKillboard；如果不想让 zKillboard 看到，请留空。

## 10. 伤害监视器与采矿

### 伤害监视器

「伤害」选项卡（默认全部关闭）：

- **「战斗时在缩略图上显示「⬆ 412 · ⬇ 95 DPS」状态条」**——输出（⬆）和承受（⬇）的每秒伤害；
- **「置顶浮窗」**——显示 DPS、峰值和单场战斗总量的小窗口；也可通过托盘 →「伤害监视器」切换；
- **「DPS 计算窗口：」**——滑动计算窗口，3–60 秒（默认 10）。

浮窗不拦截点击和焦点。要移动它，请开启编辑模式（`Ctrl+Alt+E`）并拖动。显示当前活动角色（如果正在战斗），否则显示最后一个参与战斗的角色。30 秒内没有射击即视为战斗结束。维修、能量中和、能量吸取和电子战不计入伤害。不会向磁盘写入任何数据。

### 采矿

打开方式：托盘 →「采矿」（或快捷键：「常规」→「采矿」→「打开「采矿」窗口」，默认未设置）。窗口读取所有角色游戏日志中的采矿记录：矿石、冰矿、卫星矿和气云。

- 每个角色：按类型统计的产量（数量、m³、ISK），「ISK/小时 · 10 分钟」「ISK/小时 · 本次会话」「m³/小时 · 10 分钟」「m³/小时 · 本次会话」，以及损耗。
- 暂停超过 N 分钟后开始新会话（「暂停超过此时长后开始新会话」，默认 10）。如果 GridSight 在采矿中途启动，会从日志中回溯最近 6 小时。
- ISK 按 Jita 4-4 买单计算，未扣税。「按压缩矿石计算」——有压缩形态时按压缩矿石价格计算。

**矿石舱：** EVE 不会在日志中记录舱容——请在角色卡片中填写（「矿石舱，m³」）。之后即可看到占用情况和「约 mm:ss 后装满」。卸货后点击 **「已卸货」**——从此刻起重新计算占用。「矿石舱约 95% 时高亮缩略图」会根据该估算点亮黄色「舰船」警报（每次装满提醒一次，无声音）。

## 11. 延迟与 FPS

**在哪里开启：**「常规」→「延迟与 FPS」（默认关闭），或在托盘中：

- 「延迟/FPS：缩略图」/「在缩略图上显示」——在每个缩略图状态条右侧显示 `62 fps · 38 ms`（情报文字亮起时优先显示情报）；
- 「延迟/FPS：主窗口」/「在主窗口上方显示（EVE 客户端处于焦点时）」——在当前活动 EVE 窗口的角落显示一个小浮窗；角落在「主窗口角落」中设置（默认「右上」）。独占全屏模式下不可见。

数据来自 Windows 系统跟踪（ETW，与 PresentMon 原理相同）。不会向客户端注入任何内容，默认情况下 GridSight 也不会连接 CCP 服务器。

**FPS 权限。** Windows 跟踪要求 GridSight 以管理员身份运行，或者你是 **「Performance Log Users」** 组的成员（GridSight 会显示该组在你的 Windows 中的名称）。否则缩略图上显示 `FPS：无权限`，设置中会出现 **「授予 FPS 权限（UAC）…」** 按钮：

1. 点击「授予 FPS 权限（UAC）…」并在 UAC 提示中确认。GridSight 只运行一条命令：`net localgroup "<组>" "<你>" /add`。
2. **注销 Windows 并重新登录**（或重启）——权限只有在重新登录后才生效。
3. 启动 GridSight，必要时点击「重新检查」。状态应变为「跟踪已启动：…」。

> [!IMPORTANT]
> 这是针对你**整个 Windows 用户账户**的权限，而不仅限于 GridSight：以你的身份运行的任何程序都能进行 Windows 性能跟踪。该权限会一直保留，直到你主动移除——关闭「延迟与 FPS」或卸载 GridSight 都不会移除它。撤销方法：*(beta.2+)* 点击「常规」→「延迟与 FPS」中的 **「撤销 ETW 权限（UAC）…」**（会再次请求 UAC），或以管理员身份运行设置中显示的命令 `net localgroup "<组>" "<你>" /delete`。然后重新登录。

**延迟：** GridSight 被动读取 Windows 自身为客户端与 EVE 服务器（端口 26000）之间连接测得的平滑往返时间。显示 `— ms` 表示没有连接（登录界面、离线），或客户端超过 60 秒没有发送数据。

**「通过连接服务器测延迟（每 30 秒一次）」**——默认关闭。这是无法被动测量（没有跟踪权限）时的备用方式：GridSight 向 CCP 服务器建立一个空 TCP 连接，测量握手时间后立即关闭。不传输任何数据，但对 CCP 服务器来说是额外的连接——除非需要，否则不建议开启。*(beta.2+)* 开启时 GridSight 会请求确认（「开启主动延迟测量」）。

## 12. EVE 登录 (ESI)

ESI 登录是可选的：缩略图、警报、定向扫描/本地分析、伤害、采矿和延迟/FPS 都不需要它。共有**两个相互独立的登录**，权限不同；可以使用其中一个、两个都用或都不用。

| 登录 | 位置 | 权限 | 用途 |
|---|---|---|---|
| **「连接 ESI」** | 设置 →「角色」 | 3 个只读 scope：当前位置、舰船和在线状态 | 缩略图上的「星系 · 舰船」标签；为情报功能提供当前星系 |
| **「连接角色」** *(beta.2+)* | 「面板」窗口（第 13 节），或 `GridSight.Snapshot login`（第 14 节） | 读取你的角色数据：钱包、资产、技能、工业、市场订单、合同、行星、克隆体、声望、装配等 | 「面板」、顾问、账号计时器、利润 |

完整的权限列表、每项权限的用途以及没有它会怎样：[ESI_PERMISSIONS.md](../ESI_PERMISSIONS.md)（英文）。EVE SSO 会要求一次性批准某个登录的全部权限——无法单独挑选。如果你不想给「面板」广泛的读取权限，不使用这个登录即可，GridSight 的其他功能照常工作。所有权限都是只读的，只有一项可选的创建已保存装配的权限例外，而且只能通过命令行请求（`login --fits-write`，第 14 节）。

**为标签连接角色：**

1. 「角色」选项卡 → 角色旁的 **「连接 ESI」**。
2. 浏览器会打开 EVE 官方登录页面（login.eveonline.com）。登录后**选择同一个角色**并确认授权。
3. 浏览器返回 GridSight，状态变为「ESI 已连接」。如果你在浏览器中选择了其他角色，GridSight 会连接那个角色并提示你。

标签约每 30 秒更新一次；角色下线时显示「offline」。

GridSight 使用自带的内置 ESI 应用，因此「常规」中的「EVE Developers 应用的 Client ID」**可以留空**。只有想使用自己的应用时才需要填写。

**安全：** GridSight 永远看不到你的密码——登录通过 EVE SSO 完成；登录页面会返回到你本机的 `http://localhost:8642/callback`，GridSight 只在登录过程中监听该地址。令牌只保存在这台电脑上，使用 Windows DPAPI 在你的 Windows 账户下加密（标签用 `%APPDATA%\GridSight\tokens.bin`，「面板」用 `snapshot-tokens.bin`），并且只发送到 CCP 的服务器（见第 3 节）。

**断开与撤销访问：**

- 角色旁的「断开 ESI」会删除电脑上的标签令牌，并 *(beta.2+)* 请求 EVE SSO 撤销该令牌。
- *(beta.2+)* 「面板」窗口中的 **「断开」** 用于断开当前所选角色：确认后会删除电脑上该角色的令牌，并在 EVE SSO 中撤销该令牌；快照会保留。命令行方式：`GridSight.Snapshot logout -c "<角色>"` 或 `GridSight.Snapshot logout --all`。
- 要确保访问权限已被撤销，请使用 CCP 页面：https://community.eveonline.com/support/third-party-applications/——即使磁盘上还留有副本，令牌在 CCP 一侧也会失效。

如果访问失效，托盘中会出现「重新连接 ESI…」，角色旁的按钮会变为「重新登录」。

## 13. 面板

*(beta.2+)* **「面板」** 是 GridSight 内的一个窗口，显示来自 ESI 的角色数据和顾问建议。在 1.0.0-beta.1 中这需要单独的 `GridSight.Snapshot.exe`；现在已内置。

**打开方式：** 托盘 →「面板」，或自定义快捷键：「常规」→「面板」→「打开面板」（默认未设置）。点击托盘 →「计时器」中的条目也会打开「面板」。

**首次使用：**

1. 点击 **「连接角色」**。浏览器会打开 EVE 官方登录页面——登录、选择角色并确认授权（权限见第 12 节）。
2. 点击 **「生成首个快照」**。首个快照需要几分钟：要下载游戏静态数据和市场价格。
3. 用同样的方法连接更多角色，并在窗口顶部的列表中切换。

**顶部按钮：** 「刷新」——为所选角色生成新快照；「连接角色」；「在浏览器中打开」——在默认浏览器中打开同一份报告；「断开」*(beta.2+)*——断开所选角色（第 12 节）。旁边显示快照时间。

**内容：** 关键数据、「待办」（所有部分建议的汇总）、「钱包」、「资产」及 ISK 估值、「技能」、「市场」（订单和合同）、「交易」、「工业」、「制造」、「PI」、「PI → P2」、「采矿」、「精炼」、「克隆」、「忠诚点与声望」、「深渊装配」、「装配」和「利润」。顾问包括：

- **制造**——按 Jita 价格计算你蓝图的利润；
- **精炼与采矿**——原矿出售、压缩还是精炼；
- **PI → P2**——建工厂还是出售 P1；
- **交易**——出售资产、空间站交易扫描器、监视你的订单，覆盖 5 个交易中心；
- **深渊装配**——来自 zKillboard 的热门装配，并对照你的技能和资产检查，附 Jita 批量购买清单；
- **待办**——汇总所有部分的建议。

**筛选与搜索。** 带搜索框的表格还提供按列的下拉筛选、「范围」（从–到，可以输入 `300k`、`1.5m` 这样的数值）、「N / M」计数和「重置筛选」。筛选、排序和所选交易中心会被记住。**`Ctrl+K`** 或 **`/`**（或「搜索」按钮）可在整个快照中搜索——物品、技能、地点：至少输入 2 个字母，用 ↑↓ 选择，Enter 跳转到该行，Esc 关闭。

**资产总值** *(beta.2+)*。关键数字下方是「资产总值」条：钱包 + 资产（市场估算）+ 卖单（按挂单价）+ 买单（价格 × 剩余数量，是托管资金的上限估算）的总和，附 7 天和 30 天的变化以及一张小折线图。每次快照时，GridSight 会为每个角色每小时保存一个数据点到 `%APPDATA%\GridSight\networth.json`（保留 400 天，仅保存在本地，**未加密**）；只有钱包和资产都已加载时才会保存数据点。第一次快照后，该条会提示变化将在之后的快照中出现。

**市场速览** *(beta.2+)*。「面板」的第一部分（顶部菜单中的「当前」，或托盘 →「市场速览」）是所选交易中心「交易」部分的简要汇总：**立即卖给买单**（所有立即出售更划算的物品及合计）、**挂卖单**（挂单明显更划算的物品，含价格和预计时间；合计不包含“等待较久”的条目和稀有物品）、**买入再卖出**（站内交易扫描的最佳条目；价格波动或利润率可疑偏高的条目不显示——它们仍在「交易」中）以及**调整订单**（被超价、即将过期和已过期的订单——已过期的订单需要重新挂单）。主交易中心还会显示**其他交易中心更高**：在另一个已计算的交易中心立即出售，比在这里用最佳方式（立即出售，或在建议挂单时挂单）至少高 10% 且多 300 万 ISK 的物品；稀有物品和价格波动的物品不计入，运输也不计入。条目会显示与「待办」相同的提示。条目旁的复制按钮会复制物品名称，便于在游戏市场中搜索；按住 Shift 点击复制英文名称。价格来自快照：顶部一行显示价格时效，超过一小时会提示更新快照。这只是建议而非保证——交易前请核对盘口。 *(beta.2+)* 卡片上还有 **「价格 X」** 按钮，可复制用于游戏内订单价格栏的价格：「挂卖单」为建议的挂单价，「买入再卖出」为买单价格，「调整订单」为能超过最佳竞争者的价格。

**交易中心。** 「交易」部分按 Jita、Amarr、Dodixie、Rens 和 Hek 分别计算；用「交易中心」选择器切换。经纪人费会考虑你的声望。「待办」和其他部分按 Jita 计算。

**市场动向。** 「交易」中每个交易中心都有一张「市场动向」卡片，包含三个列表：「上涨」和「下跌」（7 日均价对比 30 日均价），以及「价格跳变」（最近一天对比当月中位数）。这不是整个市场——只包括快照已经知道的物品（扫描器候选和你待售的物品堆）。

**物品卡片。** 在「面板」中任何地方点击物品名称。卡片会加载 5 个交易中心的 ESI 实时数据：最佳卖价和买价、扣除税费和经纪人费后的利润率、日成交量、订单数量以及从你当前位置出发的跳数。点击某个交易中心可查看 90 天价格历史、「利润计算器」和该空间站的订单簿，其中会标出「你的订单」。卡片还会根据价格历史给出信号（上涨、下跌、跳变、历史低价或高价、供应偏少……）和简短结论，例如「可以买入」「跨交易中心套利」，或针对你持有物品的「在哪卖更划算」。这些只是基于 ESI 历史和订单的提示，并非保证——交易前请查看订单。 *(beta.2+)* **价格提醒。** 在利润计算器下方，卡片有「价格提醒 · <交易中心>」区块（仅在「面板」窗口中，浏览器中不可用）：选择「卖价降至 ≤」或「买价升至 ≥」，输入价格（默认填入当前最佳价）并点击 **「监控」**。下方列表显示该物品的提醒，并带 **「删除」** 按钮。最多 50 个提醒；同一物品、交易中心和方向只有一个提醒，新的会替换旧的。提醒保存在本地 `%APPDATA%\GridSight\price-alerts.json`，并在与账号计时器相同的 10 分钟周期内检查，因此「监视账号计时器」必须开启（关闭时卡片会提示）。触发的提醒会出现在托盘 →「计时器」的「价格提醒」组中，托盘图标上出现圆点，并弹出一条通知；点击该行会复制当前价格。

**利润。** 「利润」部分根据你的交易计算实际利润：对所有已连接角色按 FIFO 计算，销售税取自钱包日志，计入期间内的经纪人费，制造成本按蓝图材料计算；提供期间切换、按日图表和主要物品。「无成本」列出历史中没有对应买入记录的销售（战利品、采矿、LP、合同或历史开始前的买入）——不计入利润。「已买入，尚未卖出」是 FIFO 队列中的剩余部分。ESI 只保留约 30 天的交易记录，因此 GridSight 会把它们累积到本地数据库 `%APPDATA%\GridSight\history.db` 中——每次快照时以及在后台（见下文）。

**价格库。** 在「面板」窗口中可以修正利润计算：对「无成本」中的物品使用「设置成本」（针对一批，或「用于今后所有销售」），对买来自己用的物品使用「自用」——它们会离开 FIFO 队列，不计为销售。条目可以修改或删除；GridSight 会把它们保存到 `history.db` 并刷新快照。这些按钮只在「面板」窗口中有效，在浏览器中无效。

**托盘中的账号计时器。** 在「面板」中连接角色后，GridSight 每 10 分钟检查行星开发提取器、空闲的工业槽位和技能队列。有需要处理的事项时，托盘图标上会出现圆点；列表在托盘 →「计时器」中。在同一周期内，GridSight 还会每个角色约每小时一次把钱包交易、钱包日志和工业任务同步到 `history.db`，供「利润」部分使用。「常规」→「监视账号计时器」可关闭计时器；*(beta.2+)* 同一区域中的 **「积累交易历史（每小时）」** 只关闭交易历史的后台同步（此后历史只在生成快照时更新）。

**监控你的市场订单** *(beta.2+)*。在同一个 10 分钟周期内，GridSight 会读取已连接角色的未完成订单，以及相关物品的公开市场盘口（每个角色每个周期最多 40 个盘口；其余订单只按到期时间检查）。如果同一地点、同一方向上有其他订单价格更优，则该订单为**被超价**（你自己的订单不计入）。被超价的订单、24 小时内到期的订单和已过期的订单会显示在托盘 →「计时器」中，并在托盘图标上出现圆点；每个角色超过 5 行时，其余折叠为「……另外 N 条」。点击被超价的行会复制比最佳价格好一个 EVE 价格步长（4 位有效数字）的价格，格式适合游戏内订单价格栏（无千位分隔符，小数点为英文句点）。新订单被超价时托盘通知只出现一次，同一订单不会重复通知。这使用「面板」登录本来就会请求的市场订单权限；GridSight 只读取订单，从不修改。可通过「常规」→「账号计时器」中的 **「监控我的市场订单（被超价、即将过期）」** 关闭（或直接关闭计时器）。

**网络与文件。** 「面板」页面本身无需网络即可打开。打开物品卡片时，页面会从公开的 ESI 请求实时市场数据，并从 `images.evetech.net` 加载图标；不会发送登录数据，但查询跳数时会让 CCP 知道你当前所在的星系。报告保存在 `%USERPROFILE%\eve-snapshot\`：`latest-<角色>.html`、带日期的副本 `<角色>-<日期>.html` 和 `.md`，以及 `raw\` 中的 ESI 原始响应。*(beta.2+)* 每个角色只保留最近 20 份带日期的副本（第 14 节，`--keep`）。它们包含你的钱包、资产、订单、位置等信息，且**未加密**——请不要分享。详情：[PRIVACY.md](../PRIVACY.md)、[NETWORK_CONNECTIONS.md](../NETWORK_CONNECTIONS.md)。

## 14. 面向高级用户的 GridSight.Snapshot（命令行）

`GridSight.Snapshot.exe` 是一个单独的命令行程序，生成与「面板」相同的快照并写出相同的报告。使用「面板」不需要它；它用于脚本、其他报告语言、导出深渊装配以及微调顾问参数。它与「面板」使用相同的令牌（`snapshot-tokens.bin`）。

**命令**（在 `GridSight.Snapshot.exe` 所在文件夹的终端中运行；在 PowerShell 中需加前缀 `.\`）：

| 命令 | 作用 |
|---|---|
| `GridSight.Snapshot login` | 在浏览器中登录 EVE（只读权限，与「连接角色」相同）；每个角色只需一次 |
| `GridSight.Snapshot login --fits-write` | 同上，并授予创建已保存装配的权限（仅 `--export-fits` 需要） |
| `GridSight.Snapshot logout -c "<角色>"` | *(beta.2+)* 删除电脑上该角色的令牌，并在 CCP 处撤销；`logout --all`——所有角色 |
| `GridSight.Snapshot` | 为所有已连接角色生成快照 |
| `GridSight.Snapshot -c "<角色>"` | 为单个角色生成快照 |
| `GridSight.Snapshot -c "<角色>" --export-fits <舰体\|all> [--top N]` | 把该舰体排名前 N（1–3）的深渊装配写入游戏的已保存装配，名称为 `GridSight <舰体> #N` |
| `GridSight.Snapshot --keep N` | *(beta.2+)* 每个角色只保留最近 N 份带日期的报告副本（默认 20；`0`——从不删除） |
| `GridSight.Snapshot --lang zh-Hans` | 报告语言：`zh-Hans`、`en`、`ru`、`de`（默认取 GridSight 界面语言，否则取 Windows 语言） |
| `GridSight.Snapshot --help` | 完整参数列表（`--no-open`、`--no-market`、`--no-fits`、`--hubs` 等） |

**写入账号。** `--export-fits` 是 GridSight 中唯一会修改你 EVE 账号的功能：它会**新建**名为 `GridSight …` 的已保存装配，从不修改或删除已有装配。只有在 `login --fits-write` 之后才能使用。

**文件位置：** `%USERPROFILE%\eve-snapshot\`——`latest-<角色>.html`（每次快照后会在浏览器中打开；`--no-open` 可跳过）、带日期的副本 `<角色>-<日期>.html` 和 `.md`，以及 `raw\`。HTML 文件可离线打开；点击物品时，物品卡片会从公开的 ESI 加载实时数据（第 13 节）。

## 15. 语言、更新、开机自启

**界面语言：**「常规」→「语言」→「界面语言」：「自动（跟随 Windows 语言）」、English、Русский、Deutsch、简体中文（也可用托盘 →「Язык / Language」）。立即生效。与 EVE 客户端语言无关（第 6 节）。来自 CCP 数据的物品名称在除俄文以外的所有界面中均显示为英文。

**更新：**「检查更新（每天一次，GitHub）」默认开启。GridSight 每天向 GitHub 查询一次是否有新版本。如果有——托盘菜单中出现「有新版本 X…」，弹出一次通知，「关于」中也会显示一行提示。**GridSight 从不自行下载或安装任何内容**——请手动更新（第 2 节第 9 步）。「包含测试版」——测试版也会提示。手动检查：「关于」→「检查更新」，或 *(beta.2+)* 托盘 →「帮助与反馈」→「检查更新」。

**免打扰时段** *(beta.2+)*。「常规」→「通知」：勾选**「免打扰时段」**，并在两个时间选择框中设置小时（00:00–23:00）。也可以跨越午夜——23:00 — 07:00；两个值相同表示全天。在免打扰时段内，GridSight 不会弹出有关价格、订单或快照完成的通知；托盘图标上的圆点和「计时器」中的条目仍然保留。首次启动和数据迁移的提示始终显示。默认关闭（默认时段 01:00–08:00）。**「测试通知」**按钮即使在免打扰时段内也会显示一条示例通知。如果完全看不到通知，请检查 Windows 的“勿扰模式”。

**迁移到另一台电脑** *(beta.2+)*。「常规」→「迁移到另一台电脑」：**「导出设置…」**会写出一个 .zip，其中只有 `settings.json`、`layout.json`、`timers.json`、`mining.json` 和 `price-alerts.json`。ESI 令牌（`*.bin`）、交易历史（`history.db`）、资产总值历史、日志和缓存永远不会包含在内——请在新电脑上重新连接角色。**「导入设置…」**会检查归档（只允许这些文件名，每个不超过 2 MB，且每个都是 JSON 对象）并将其暂存；导入会在下次启动 GridSight 时生效（托盘 →「退出」，然后重新启动）。原有文件会复制到 `%APPDATA%\GridSight` 中设置旁的 `backup-<日期-时间>` 文件夹。

**开机自启：**「常规」→「启动」→「随 Windows 启动 GridSight」。会把 GridSight 加入当前用户的启动项（注册表 `HKCU\…\Run`）；取消勾选即移除。

## 16. 故障排除 (FAQ)

**没有缩略图。**
- EVE 是否以「窗口」或「无边框窗口」模式运行（不是全屏）？
- 是否开启了「EVE 不在前台时隐藏所有缩略图」？开启后，其他程序处于活动状态时缩略图会隐藏。
- 是否开启了「隐藏当前活动客户端的缩略图」？只有一个客户端时，它处于活动状态期间缩略图会隐藏。
- GridSight 是否在运行（托盘中有图标，可能在 **^** 下面）？

**缩略图位置不对 / 跑到屏幕外。** 开启编辑模式（`Ctrl+Alt+E`）并拖动它。拔掉显示器后，缩略图会移到主屏幕，显示器重新接上后会回到原位。缩略图与角色绑定：在选择角色之前，新客户端显示「登录中…」。

**FPS 显示「FPS：无权限」或「— fps」。**
- 「FPS：无权限」——授予权限（第 11 节），然后**注销 Windows 并重新登录**，再点击「重新检查」。
- 「虽然你已在组中，但仍没有跟踪权限」——点击「重新检查」或重启电脑。
- 「— fps」——该客户端暂无数据，或跟踪启动失败；请查看设置中「延迟与 FPS」下方的状态。如果提示残留了跟踪会话，请按提示操作（以管理员身份运行 `logman stop … -ets`）或重启电脑。

**延迟显示「— ms」。** 客户端未连接服务器（登录界面、角色选择、离线），或 60 秒内没有发送任何数据。没有跟踪权限就无法被动测延迟——请授予权限，或开启「通过连接服务器测延迟（每 30 秒一次）」。

**警报不触发。**
1. 「常规」→「EVE 日志文件夹」下方应显示「已找到：正在读取 Gamelogs 和 Chatlogs。」。
2. 「EVE 客户端语言（用于解析日志）」应为「自动」或你的客户端语言。目前只支持俄文和英文客户端，英文仍在测试中；中文客户端的日志暂不解析。
3. 活动客户端永远不会触发警报——请用后台客户端测试，或在「警报」选项卡中点击「测试」。
4. 检查该类警报在「警报」或该角色的「角色」选项卡中没有被关闭，且托盘中没有勾选「暂停警报」。
5. 本地和情报需要在 EVE 中开启聊天记录（第 2 节第 6 步）。

**「面板」窗口是空的，或提示「需要 WebView2 Runtime」。** 用「下载 WebView2 Runtime」安装该组件，在此之前可以先用「在浏览器中打开」。

**「Windows 已保护你的电脑」。** 这是正常现象——GridSight 没有签名。先核对 SHA-256（第 2 节第 1 步），然后点击 **更多信息 → 仍要运行**。

**GridSight 无法启动 / 显示错误。** 错误信息中会注明日志位置。如果设置文件损坏，GridSight 会自动从 `settings.json.bak` 恢复设置。

**GridSight 日志在哪里、提交 Issue 时要附上什么。** 日志位于 `%APPDATA%\GridSight\logs\`（每天一个文件，`gridsight-YYYYMMDD.log`；*(beta.2+)* 超过 14 天的文件会被删除；备用文件夹为 `%TEMP%\GridSight-logs`）。日志中包含角色名，但不包含令牌。请使用[错误报告表单](https://github.com/evelens-app/evelens/issues/new?template=bug_report.yml)提交 Issue（或 *(beta.2+)* 托盘 →「帮助与反馈」→「报告错误」），并注明：
- GridSight 版本（「关于」）；
- Windows 版本、EVE 窗口模式、EVE 客户端语言、客户端数量和显示器数量；
- 你做了什么、预期是什么、实际发生了什么（附截图会很有帮助——但不要发布带有钱包或资产的「面板」截图）；
- 当天日志中的相关行，而不是整个文件。Issues 是公开的：请替换角色名，切勿发布令牌、钱包或资产信息。

安全问题请私下报告，不要发在 Issues 中：[SECURITY.md](../SECURITY.md)。
